# SK Sungai Tiram — Kempen Hijau PWA

## Terbitkan di GitHub Pages
1. Ekstrak ZIP ini.
2. Cipta repository GitHub, kemudian pilih Add file > Upload files.
3. Muat naik SEMUA kandungan folder ini terus ke akar repository. Pastikan index.html berada pada aras utama, bukan di dalam folder tambahan. Jangan muat naik ZIP sahaja.
4. Buka Settings > Pages > Build and deployment.
5. Pilih Deploy from a branch, branch main dan folder / (root), kemudian Save.
6. Tunggu penerbitan dan buka URL yang diberikan oleh GitHub Pages.

Semua laluan aset adalah relatif, sesuai untuk laman repository GitHub Pages.

## Pasang sebagai aplikasi
- Android/Chrome/Edge: buka laman HTTPS, gunakan butang Pasang aplikasi apabila tersedia atau menu pelayar > Install app/Add to Home screen.
- iPhone/iPad Safari: Share > Add to Home Screen.
- Buka laman sekali ketika dalam talian untuk menyimpan kandungan luar talian.

## Sokongan luar talian
Halaman utama, data, gambar, ikon dan gaya disimpan oleh service worker. Video TikTok dan pautan luar memerlukan internet. Pilihan tindakan disimpan pada pelayar/peranti sahaja; tiada pangkalan data pelayan.

## Kemas kini
Edit index.html atau fail aset, kemudian commit ke GitHub. Tukar skst-hijau-v1 dalam sw.js kepada v2, v3 dan seterusnya apabila aset berubah. Muat semula semasa dalam talian.

## Video
Video TikTok dipaparkan menggunakan pemain terbenam 9:16. Main balik tertakluk kepada ketersediaan TikTok dan tetapan pelayar. Butang pautan TikTok disediakan. Tiada fail MP4 disertakan.

## Kandungan
Laman mengandungi lencana, dokumentasi kempen, enam tonggak, data tenaga/air, Eco Garden, nota semakan data dan animasi hover. ZIP ini tidak mengandungi kelayakan akses, konfigurasi Sites atau dokumen sumber dengan maklumat hubungan peribadi.
